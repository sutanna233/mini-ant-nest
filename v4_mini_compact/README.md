# 迷你 3D 打印蚁巢 (Mini Ant Nest)

一个超小的可 3D 打印蚁巢：**76 × 46 × 14 mm** 底板 + **2 mm 盖板**，
包含完整的**活动区、4 个巢室、连接通道、保湿槽**和**对外接管口**。
全部为竖直挖空（2.5D），**免支撑**，普通 FDM 打印机可直接打印。

## 文件结构

```
generate_nest.py        参数化生成脚本（改尺寸/改布局只改这里）
design/nest_base.stl    底板（蚁巢主体）—— 直接切片打印
design/nest_cover.stl   盖板（带透气孔 + 加水孔）
preview/                蓝图与 3D 预览渲染
preview/_check.py       几何自检脚本（验证微缝连通性等）
```

## 设计说明

| 区域 | 说明 |
|------|------|
| 活动区 Outworld | 28 × 40 mm 大空腔，深 10 mm，左侧墙体防逃；内含 Ø8 mm 浅食盘（喂蜂蜜/水） |
| 巢室 A–D | 4 个 Ø12 mm 圆室，深 10 mm，用 3.5 mm 通道连成环，可分级/分区饲养 |
| 入口通道 | 活动区 → 巢室 A，宽 4 mm |
| 保湿槽 H₂O | Ø11 mm、深 12 mm 独立水槽，塞吸水棉 |
| 微缝（保湿核心） | 保湿槽与巢室 C/D 之间留 **3 条 0.6 mm 竖缝**（z=6 以上），水汽缓慢扩散；**z<6 保持封闭，不渗水、不漏水** |
| 管接口 | 左侧 Ø6 mm 穿墙圆孔，可接外接活动区 / 试管 / 软管 |

**保湿原理**：水存在独立的保湿槽里（不漫进巢室），只有水汽通过细缝扩散到巢室，
形成稳定高湿微环境。底板最薄处 2 mm（保湿槽底），巢区地面 4 mm，强度足够。

尺寸参数都在 `generate_nest.py` 顶部，改完重新运行即可生成新 STL。

## 打印建议

- **材料**：PLA 或 PETG（PETG 更耐湿、更好清洗）。保湿槽长期接触水，PETG 更推荐。
- **层高**：0.16–0.2 mm；**喷嘴**：0.4 mm。
- **支撑**：不需要。
- **外壳/壁数**：3–4 圈；**填充**：25–30%（保湿槽壁要致密，防渗水）。
- **方向**：两块都平放（开口朝上）直接打印。
- 打印后把 **保湿槽内壁** 用少量清漆/指甲油薄涂一层可进一步防渗（可选）。
- 盖板与底板的密封：可用胶带、橡皮筋或亚克力/玻璃片（74 × 44 mm）替代盖板，观察更好。

## 组装与使用

1. 打印 `nest_base.stl` 和 `nest_cover.stl`。
2. 把一小块**吸水棉/珍珠棉/水苔**塞进保湿槽（H₂O 槽）。
3. 从盖板预留孔（或取下盖板）给棉加水，加到棉**饱和但不积水**。
4. 盖好盖板（活动区孔透气，巢区基本封闭保湿）。
5. 食物放活动区的食盘里；可接软管把管接口连到更大的活动区。
6. **补水**：视气候每 3–7 天加一次水；空气干燥/开空调时可缩短间隔。
   如果巢内壁出现水珠（过湿），短暂打开盖子或减少加水量即可。
7. 幼虫/卵期可把湿棉加到较满提高湿度；干爽偏好品种可只加到半湿。

## 重新生成 / 自定义

```powershell
python generate_nest.py
```

常用可调参数（脚本顶部）：
`W, D, H` 底板尺寸；`CH_R` 巢室半径；`CH_W` 通道宽；`WELL_R` 保湿槽半径；
`VENT_W`/`VENT_OFFSETS` 微缝宽度与数量；`CHAMBERS` 巢室坐标。

## 依赖

Python 3.11+，`shapely`、`trimesh`、`manifold3d`、`numpy`、`matplotlib`。

# 紧凑型小群落蚁巢 v0.6（石膏保湿 + 亚克力磁吸网盖）

面向**新后 / 初创小群落（几只 ~ 几十只）**的紧凑型 3D 打印蚁巢。
打印巢体 + 浇筑石膏保湿层 + 亚克力磁吸观察盖 + 304 金属网压框。
造型：**大圆角轮廓 + 二级底座裙边 + 顶部围栏**（盖板嵌入围栏内，与围栏上沿齐平）。

> 本包是**打样起点**，不是"通用蚁巢"。所有尺寸需按目标物种、实测亚克力厚度、实测磁铁尺寸复核。
> 本设计**不宣称防逃适用于所有蚂蚁**，石膏的耐久/干燥表现必须实测。

---

## 1. 目标与假设

| 项 | 本版假设 |
|----|----------|
| 目标物种 | **未定**，按保守小群落方案 |
| 群落阶段 | 新后 / 初创小群落（几只 ~ 几十只） |
| 湿度方案 | 巢区底部 **5 mm 浇筑石膏** + **外部注水井**（不在巢内维持积水） |
| 工艺 | FDM，0.4 mm 喷嘴，PETG（首选）/ PLA，免支撑 |
| 核心外形 | 60 × 88 × 38 mm；含二级底座 ≈ **65 × 93 × 41 mm** |
| 现成零件 | 无，全部重新设计 |

外形与分区（俯视，前=活动区/注水井，后=巢区）：

```
 y=88 ┌──────────────────────────────┐
      │  巢室A     │ 巢室B  │  巢室C   │  ← 巢区(y49..85)，底部 5mm 石膏
 y=49 ├──────────┬───┬────────────┬───┤
      │          │门 │   过水通道  │   │  ← 实心隔断带(y34..49)：挡水
 y=34 ├──────────┴───┴────────────┴───┤
      │   活动区(干)   │   注水井(加水)  │  ← 前带(y3..34)
 y=0  └──────────────────────────────┘
        x=0                            x=60
```

- **干湿分离**：活动区地面干燥（`Z_FLOOR=8`），只有巢区与注水井有石膏/水。
- **注水口与巢室分开**：加水孔在活动区盖上、正对注水井，水经 `4×5 mm` 通道进入石膏，**不会**直接灌进巢室。
- **顶部围栏**：巢体顶面四周有 3 mm 高围栏，两块亚克力盖嵌入其中并与围栏齐平；围栏在拉手处留缺口。
- **观察**：活动区盖透明（含通风窗），巢区盖透明（全封闭、避光）。
- **磁吸**：磁铁**只装在打印巢体**的磁柱孔里；亚克力盖上用 **磁性钢 M3×6 螺钉 + 螺母**。

## 3. 打印参数（起点）

- 材料：**PETG 首选**（耐湿、层间好）/ PLA 可行。
- 0.4 mm 喷嘴，0.2 mm 层高，**5 壁**，6 顶/底，20–30% 填充，**免支撑**。
- `mesh_clamp`：**贴网面朝下平放**，保证压网面平整。
- `nest_body`：按源文件默认姿态直接打印。**石膏腔与 4×5 通道内不得残留封死的支撑或拉丝**，否则水路被堵。
- `entrance_reducer`：平放打印。

> 底板为 3 mm 实心底，层间粘接不足会渗水；若发现渗漏，把 `PLATE` 调大或提高壁数/填充。

## 4. 装配步骤

1. **试装（先不放石膏、不放活体）**
   - 把亚克力盖放到巢体上，检查是否平整、四角是否翘起。
   - 用 `preview/_check.py` 的结论对照实物：门洞、过水通道、8 个磁孔位置是否正确。
2. **装磁铁**：把 8 个 Ø6×2 mm 磁铁压入巢体磁柱孔，顶面**略低于**孔口即可（可用少量胶固定）。
3. **装盖用钢件**：把 M3×6 磁性钢螺钉从上方穿过亚克力盖的 Ø3.4 孔，下面旋上 M3 螺母（螺母落进磁柱孔内）。**先确认螺钉/螺母确实被磁铁吸住**；304 不锈钢不吸，不能替代。
4. **装网压框**：
   - 把 28×18 mm 的 304 网片盖在活动区盖的 20×10 mm 通风窗上方，四周各压 4 mm。
   - 盖上 `mesh_clamp`，用 4 颗 M3×8 拧入亚克力 Ø2.5 预钻孔（轻载，自攻）。**不要给网片打孔**；4 颗螺钉位于网片边缘之外。
   - 对角顺序轻拧，拧完检查整圈网片不能滑动、不能有缝。
5. **放盖**：两块盖分别嵌入顶部围栏内（前拉手朝前、后拉手朝后，卡进围栏缺口），磁吸闭合；盖板应与围栏上沿齐平。

### 关于亚克力厚度（重要）

磁孔深度按 `POCKET_D = 5.0 mm`、名义亚克力 3.0 mm、M3×6 设计。
名义 3 mm 板材实测常为 2.8–3.3 mm，会改变螺钉尖端到磁铁面的间隙。**采购后先实测**，必要时：

- 调整 `generate_nest.py` 顶部 `POCKET_D`（≈ 磁铁厚 + 螺母厚 + 螺钉余量），或
- 改用 M3×5 / M3×8 螺钉匹配实际厚度。

## 5. 浇筑石膏

- 材料：**无香精、无抗菌/防霉/防水添加剂的陶瓷模具石膏**（约 1 kg，单件浆料约 5 mL）。
- 按**供应商给出的粉水比**调配（不同产品不能套用同一比例）；一种陶瓷模具石膏实测规格为 100 g 粉 + 31–32 g 水，初凝 8–15 min、终凝 30–60 min，**仅作参考**。
- 浇筑：从注水井或巢区盖开口处缓慢倒入，让浆料经 4×5 通道流满巢区底部 5 mm 石膏腔。轻敲排气泡。
- **完全干燥后再用**。检查是否有空洞、裂纹、浮粉、渗漏。

> 石膏的**材质、浇筑质量、干燥行为、被蚂蚁挖穿的风险**都需实际测试。
> **不得**用装饰香薰石膏、防水腻子或成分不明的"高硬度粉"替代。
> 巢内**不维持**积水，水只加在**外部注水井**。

---

## 6. 加水与维护

- 加水：打开注水孔塞，向**注水井**加水至约 2/3，塞回。
- 补水周期按环境试验确定（参考 3–7 天一次）；以石膏微湿、巢室内壁**不挂水珠**为准。
- 清洁：取下盖，取出石膏层（如可拆）或用软毛刷 + 清水冲洗巢室，阴干后再用。**不要用洗涤剂残留**。

---

## 7. 放活体前的验收（必须逐条做完）

1. **干装检查**：盖平整、磁吸闭合不翘边；门洞/通道与图纸一致。
2. **反复开合盖**：≥ 10 次开合，检查磁吸力、螺钉/螺母是否被带出、网片是否移位。
3. **漏水 / 干湿循环**：注水井多次加水→排空，检查底板、通道、隔断带是否渗漏；石膏是否开裂、掉粉。
4. **逃逸缝隙检查**：在**二次防逃容器**里空置运行 **≥ 48 小时**，针对目标物种检查门洞、盖缝、网目边缘的逃逸可能。
5. 上述全部通过后，才可放入蚂蚁。

> 网片需到货后逐张检查**散丝、边缘缺口**；100 目并不意味着对所有小型蚁都安全。
> 可选：打一块小**特征试片**（薄石膏 + 网 + 磁吸）先做材料级测试；若明确跳过，上面的未验证风险需保留记录。

## 8. 采购与合规

- 采购前必须书面确认：**确切材质、网目/孔径、尺寸、数量、运费、加工公差**。
- 亚克力、磁铁、石膏这类物料，需问清是否含**香精/抗菌/防霉/防水/色素**等添加剂（涉及动物接触）。
- **报价（询价得到的 ex-ante 价格）与实际付款金额分开记录**。
- **未获授权不下单、不代付**；订单进行到付款页即停止，并报出准确总额。

> 说明：本仓库中出现的任何规格均为**设计要求**，磁铁/亚克力/网的**到货实测值以实际为准**。

---

## 9. 主要未验证风险（交付时保留）

- 石膏层对目标物种的耐久性与被挖掘风险。
- 100 目网对"极小体型"蚂蚁的逃逸风险。
- 亚克力实际厚度偏差导致的磁吸间隙变化。
- M3×6 钢螺钉与 Ø6×2 磁铁的**实际吸力**是否足够（需实测）。
- 巢体为 3 mm 底板的渗漏风险。

## 10. 修改参数

所有关键尺寸在 `generate_nest.py` 顶部集中定义：外形 `SX/SY/H` 与圆角 `R`、底座 `BASE_*`、顶部围栏 `RIM_*`、
石膏厚 `Z_FLOOR-GYP_Z0`、分区 `ACT/WELL/DIV/NEST`、门洞 `DOORWAY`、过水 `CHANNEL`、磁吸 `MAG_*`、
盖板 `ACT_COVER/NEST_COVER/COVER_R/SEAM`、网盖 `WINDOW/CLAMP/MESH`。
改完运行 `python generate_nest.py` 即可重新导出 STL / DXF / 预览，并跑 `python preview/_check.py` 自检。
